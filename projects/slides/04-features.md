# List of features offered by the solution

| Feature                        | What it does                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------------- |
| 15-minute hydro sync           | 4 MRC gauges plus 7-day rain and soil moisture. Automatic station failover.                           |
| Commune risk engine            | 1,661 communes indexed, 1,544 scored, 4 risk tiers, DEM elevation, target 36 to 72 hour lead time.    |
| Stage-aware directives         | Harvest, fertilizer hold, sluice prep, or move assets, based on rice stage and rain.                  |
| Khmer voice bulletins          | 30 to 60 second Gemini voice notes, cached MP3, playable on low-cost smartphones.                     |
| Telegram and web delivery      | GPS pin risk card, stage onboarding, public channel, risk map, commune page.                          |
| Agentic officer assistant | ReAct tool calls for telemetry, evidence, crop directives, drafts, and publishing. Khmer voice input, watch inbox, officer approval, field reports. |

**One system, three surfaces:** bot, console, and voice page.
